**Markdown Import**: The editor now registers the official `@tiptap/markdown` extension. `setContent(markdown, { contentType: 'markdown' })` imports Markdown, `setContent` also accepts a `JSONContent` object, and both work with the other options (`resetHistory`, `preserveSelection`, `preserveScroll`). `@tiptap/markdown` is a new peer dependency (about 19 kB gzipped). A `Markdown` instance passed in `tiptapExtensions` replaces the built-in one without a warning.
