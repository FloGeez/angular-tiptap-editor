**Link Text Field in the Link Bubble Menu**: The link bubble menu only edited the URL, so a link's displayed text could not be changed from the UI. It now has a "Link text" field above the URL. The field shows the text of the link, or the selected text when a link is being added, and changing it replaces that text while keeping its formatting, in the same undo step as the link. Leaving it empty keeps the current text, and it is hidden when the selection spans several blocks.
