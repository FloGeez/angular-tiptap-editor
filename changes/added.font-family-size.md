**Font Family and Font Size**: Opt-in menus for the toolbar and the text bubble menu (`toolbar.fontFamily`, `toolbar.fontSize`, `bubbleMenu.fontFamily`, `bubbleMenu.fontSize`). The font button draws "Aa" in the current font and opens a grid of fonts. The size control shows `− 16 +` and turns into the neighbouring sizes on hover: click a neighbour, hold it or drag to change the size, or open a row of sizes with a slider and a size field. `Mod+Shift+.` and `Mod+Shift+,` step the size. Set the choices with `fonts: { families, sizes }`. While a font menu is shown, fonts and sizes pasted from other apps, such as Word, are kept like colors; without it they are dropped, as before. Choose either way with `paste.fontFamilies` and `paste.fontSizes`.
