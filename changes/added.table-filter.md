**Filter Table Rows by Column**: The column menu of tables with a header row now filters the rows by that column: a date range, a number range, a checkbox per value (with its count and `(empty)`) when the column has few values, or a text search without case or accents. Filters of several columns combine, a bar above the table shows how many rows are visible with a button to clear them, and the row being edited stays visible. Filters only hide rows on screen, so the saved and exported content does not change, and while rows are hidden copy, cut, paste, typing, Delete, the arrow keys and Tab only reach the visible rows, and row and cell operations that would change hidden rows are blocked. Formatting over a selection that spans hidden rows (marks, alignment, block types, cell attributes) applies to the visible rows only. The `setTableColumnFilter`, `clearTableFilters` and `revealTableRow` commands filter from code.
