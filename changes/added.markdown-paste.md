**Pasting Markdown**: Plain text that contains Markdown syntax (headings, lists, quotes, code fences, tables, bold, links...) is now parsed when pasted, also when it is copied from VS Code. Text without Markdown syntax, a paste as plain text (Mod+Shift+V) and a paste into a code block stay line by line as before, and HTML on the clipboard is not affected. Turn it off with `paste: { markdown: false }`.
