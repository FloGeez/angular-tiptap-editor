**Markdown Keeps Every Format**: Markdown has no syntax for superscript, subscript, text alignment, text colors, highlight colors or image sizes, so the Markdown export used to drop them. A paragraph or heading that uses one of them is now written as HTML, and a resized or aligned image as an `<img>` tag. `@tiptap/markdown` reads them back, so a Markdown round trip keeps them, and GitHub and other Markdown renderers display them. Other blocks stay plain Markdown. For this, paragraph and heading are now the library's own nodes instead of StarterKit's (`starterKitOptions.paragraph` and `heading` still apply), and `@tiptap/extension-paragraph` and `@tiptap/extension-heading` are new peer dependencies.
