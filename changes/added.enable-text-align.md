**`enableTextAlign` Option**: Text alignment can now be turned off with `enableTextAlign: false` (input or `AteEditorConfig` key, default `true`). The `TextAlign` extension is not registered, so the `textAlign` attribute leaves the schema, `Mod+Shift+L/E/R/J` do nothing and pasted `text-align` styles are dropped. The toolbar and image bubble menu alignment buttons are hidden whatever their own config says. Changing it at runtime re-creates the editor.
