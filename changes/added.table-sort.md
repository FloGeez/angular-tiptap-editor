**Sort Table Rows by Column**: Tables with a header row show a menu button in each header cell that sorts the rows by that column, ascending or descending. The column type (date, number or text) comes from its values, so `1.234,5`, `1,234.5` and `dd/mm/yyyy` dates sort as expected; empty cells go last and rows with equal values keep their order. The header row stays in place, a single undo restores the previous order, and the sorted column shows an arrow while the rows keep that order. The `sortTableColumn` command sorts from code.
