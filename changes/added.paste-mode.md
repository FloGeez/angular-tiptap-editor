**Keep, Clean Up or Ask on Paste**: `paste.office` (Word, Excel) and `paste.external` (web pages, Google Docs and other apps) choose what happens to pasted formatting: `merge` keeps it as today (the default), `clean` drops colors, highlights, fonts and sizes while headings, lists, tables, links, bold and italic stay, and `prompt` pastes it as in the document, fonts and sizes included, then shows **Keep | Clean up** next to the pasted text. The prompt never takes the focus: Enter, Escape, typing or moving on keep the formatting, `Ctrl+Shift+Backspace` cleans it up, and a single undo brings it back.
