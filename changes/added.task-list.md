**Task Lists**: GFM task lists (`- [ ] item`) now work out of the box. `TaskList` and `TaskItem` (with nested sub-tasks) are always registered, the `taskList` slash command is on by default in all five locales, and a `taskList` toolbar button next to the lists is available (off by default, `toolbar: { taskList: true }`). The checkboxes are styled by the library and themable with `--ate-task-checkbox-size`, `--ate-task-checkbox-color`, `--ate-task-gap` and `--ate-task-checked-text-color`. A `taskList` / `taskItem` passed in `tiptapExtensions` replaces the built-in one. `@tiptap/extension-list` is now a peer dependency, and the demo uses the built-in task list instead of its own extension.
